# Bayesian Experimental Design, Model Discrepancy, AD-EKI, and Wasserstein distance

This repository accompanies the paper:

**Huchen Yang, Xinghao Dong, and Jin-Long Wu,
“Bayesian Experimental Design for Model Discrepancy Calibration: A Rivalry between Kullback–Leibler Divergence and Wasserstein Distance.”**

The code, data, and scripts used to generate the numerical results in the paper are currently being organized and documented.

**The complete materials will be uploaded to this repository soon.**
